Now what?

A test fires. How likely is it to be right? The answer depends far more on how rare the thing is than on how good the test is, and almost everyone’s intuition gets this wrong by an order of magnitude.

How common it is. A rate, a percentage, or “1 in N”.

Sensitivity. P(test positive | has it).

Specificity. P(test negative | does not have it).

Positive predictive value — if it tests positive, the chance it is real

The confusion matrix

The same four numbers, arranged so both directions are visible. The rates you were given run down the columns; the rates you wanted run across the rows.

Change the base rate and watch it: the column rates never move — they are properties of the test. The row rates move a great deal.
