Where your token goes

Nowhere. Decoding is string manipulation, so it happens in this tab and the token is never sent, stored or logged. The only network requests this page makes are for its stylesheet and fonts, once, when it loads — before you have pasted anything. Open your network tab and watch: pasting a token produces no requests at all.

If you would rather not take that on faith, save this page and open it with the network off. It works exactly the same.
