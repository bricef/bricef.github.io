Tools

Small things that do one job. Each runs entirely in your browser — no accounts, no servers, nothing sent anywhere.

Deciding

Working out what you think

  • Ranker Order a list by choosing between two things at a time. →
  • Decision matrix Score options against criteria you weighed by comparison, not guesswork. →
  • Calibration trainer Find out whether your “90% sure” is actually 90%. →
  • Base rate calculator A test fired. How likely is it to be right? Rarer than you think. →
  • Queueing calculator How many workers you need, and why 90% full is already too full. →

Decoding

Making something opaque readable

  • Cron explainer Read an expression in plain English, and see when it really fires. →
  • Token inspector Decode a JWT without handing it to someone else's website. →
  • Bit twiddler One number in every base at once, with the bits as the interface. →

Doing

Getting through the thing itself

  • Talk timer A countdown you can read from a podium, that counts up once you are over. →
